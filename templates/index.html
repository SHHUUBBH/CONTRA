Bring Your Own Key

The project's Groq LLaMA API quota has been reached. Please bring your own Groq API key to test and use CONTRA.

Groq Platform • LLaMA 3.3
Open Groq Console
1 Click console.groq.com/keys to visit Groq platform.
2 Sign up or log in (free) and click "Create API Key".
3 Copy your key (starts with gsk_) and paste it below to unlock the project.
Your API key is stored safely in your browser session only. You can pull (take out) your key anytime via the Pull API Key option on the dashboard.

Pull Out Your API Key?

This will take out and clear your Groq API key from this browser. The project will be locked until a key is entered again.
